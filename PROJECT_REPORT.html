MINI PROJECT

SAFECAMPUS - COLLEGE CYBERBULLYING PREVENTION & INCIDENT REDRESSAL PLATFORM

1. AIM

To design and develop a responsive, client-side College Cyberbullying Prevention & Incident Redressal Platform using HTML, CSS (Windows 8 Metro UI Kit) and JavaScript with browser LocalStorage database persistence and client-side Natural Language Processing (NLP) toxicity detection.

  • Reduce fear and stigma in reporting campus cyberbullying through 100% confidential intake.
  • Allow students to analyze suspicious comments or direct messages in real time for toxic patterns.
  • Enable categorized grievance intake across social media platforms (Instagram, WhatsApp, Discord).
  • Generate digital incident tracking keys (CBP-2026-XXXX) and printable grievance receipts.
  • Provide an interactive 5-stage case progress timeline and counselor support line.
  • Provide administrative controls for disciplinary officers to inspect evidence dossiers and update case stages.
  • Support mobile, tablet, laptop, desktop and kiosk displays with zero server dependency.

3. PROCEDURE

  1. Design the User Interface:
    The SAFECAMPUS interface was designed using HTML5 and CSS3 following the Windows 8 Metro UI Kit. The interface includes the navigation bar, live tile hub, AI toxicity test bench, anonymous incident wizard, progress tracking timeline, counseling line, legal rights cards and administrative grievance sections.
  2. Develop the Frontend:
    JavaScript was used to implement tab navigation, live tile interactions, evidence file handling, grievance form validation and dynamic updating of the application.
  3. Develop the AI NLP Toxicity Engine:
    A client-side rule-based and lexical Natural Language Processing classifier was developed to evaluate threat patterns, blackmail phrases, hate speech and derogatory insults to compute an aggregate toxicity score (0–100%).
  4. Integrate the Database:
    HTML5 LocalStorage was integrated as the persistent client-side database to store grievances, complainant credentials, timestamps, investigation notes and resolution statuses locally.
  5. Implement Incident Reporting:
    The student selects reporting privacy (Anonymous vs. Identified), specifies incident category and digital platform, enters the description, attaches evidence screenshots and confirms the report.
  6. Generate Digital Token and Grievance Receipt:
    After successful incident submission, a unique Case Tracking ID (e.g. CBP-2026-1042) and printable digital grievance receipt are generated containing relevant complaint and verification metadata.
  7. Implement 5-Stage Case Tracking:
    The complainant can monitor grievance progress across five sequential verification stages: Submitted, AI Triaged, Under Investigation, Action Taken, and Resolved.
  8. Implement Responsive Design:
    CSS responsive rules and flex/grid layouts were used to adapt the application to mobile phones, tablets, laptops, desktops and kiosk displays. Portrait and landscape orientations are supported.
  9. Test the Application:
    The major application modules were tested, including anonymous intake, identified intake, AI threat pattern classification, evidence drag-and-drop, case lookup, counselor replies, admin authentication and CSV audit export.
  10. Deploy the Application:
    The complete static frontend was verified for zero-server execution and pushed to the remote GitHub repository.

5.3 JavaScript – Real-Time AI Toxicity Engine

const ToxicityEngine = (() => {
  const THREAT_PATTERNS = [
    /kill\s+(yourself|urself|you)/i,
    /watch\s+your\s+back/i,
    /i('ll| will)\s+(hurt|beat|expose|ruin|destroy|leak|find)\s+you/i,
    /i\s+know\s+where\s+you\s+live/i
  ];

  const STALKING_PATTERNS = [
    /send\s+(nudes|private\s+pics|photos)\s+or\s+else/i,
    /i\s+have\s+your\s+(photos|chats|videos|secrets)/i,
    /leak\s+your\s+(number|address|pics)/i
  ];

  function analyze(text) {
    if (!text || text.trim().length === 0) {
      return { overallScore: 0, severity: "Safe", riskLevel: "Low" };
    }
    let threatScore = 0, blackmailScore = 0;
    THREAT_PATTERNS.forEach(p => { if (text.match(p)) threatScore += 45; });
    STALKING_PATTERNS.forEach(p => { if (text.match(p)) blackmailScore += 40; });

    let rawTotal = (threatScore * 0.45) + (blackmailScore * 0.35);
    if (threatScore >= 45 || blackmailScore >= 40) rawTotal = Math.max(rawTotal, 85);
    const overallScore = Math.min(100, Math.round(rawTotal));

    return {
      overallScore,
      severity: overallScore >= 75 ? "Severe Threat" : overallScore >= 40 ? "Moderate" : "Safe",
      riskLevel: overallScore >= 75 ? "Critical" : "Low"
    };
  }
  return { analyze };
})();

5.4 JavaScript – Incident Intake & Case Tracking Handler

function submitIncident(formData) {
  const randomCode = Math.floor(1000 + Math.random() * 9000);
  const newCaseId = `CBP-2026-${randomCode}`;
  const timestamp = new Date().toISOString();

  const newIncident = {
    id: newCaseId,
    timestamp,
    reportingType: formData.reportingType,
    studentName: formData.studentName || "Anonymous Student",
    category: formData.category,
    platform: formData.platform,
    urgency: formData.urgency,
    description: formData.description,
    status: "Submitted",
    toxicityScore: ToxicityEngine.analyze(formData.description).overallScore,
    notes: [{
      date: new Date().toLocaleDateString() + " " + new Date().toLocaleTimeString(),
      text: "Complaint lodged via SafeCampus Student Portal. Assigned to Grievance Redressal Cell."
    }]
  };

  const incidents = getStoredIncidents();
  incidents.unshift(newIncident);
  localStorage.setItem("safecampus_incidents", JSON.stringify(incidents));
  return newIncident;
}
